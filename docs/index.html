SmallBASIC PiGPIO 2

If you want to let a LED blink or measure the temperature in your room, you can use SmallBASIC on a Raspberry PI. As an example you can connect a LED and a resistor to a GPIO-Pin of your Raspberry Pi, write a short SmallBASIC programm and enjoy the blinking LED:

import gpio

const PIN_GPIO4 = 4

gpio.SetOutput(PIN_GPIO4)

for ii = 1 to 5
  gpio.Write(PIN_GPIO4, 1)
  delay(500)
  gpio.Write(PIN_GPIO4, 0)
  delay(500)

News

July 31 2025: Add support for ST7789 color TFT displays

July 11 2025: SmallBASIC PiGPIO 2 supports now all Pi’s from Zero to 5. It can even run on other LINUX systems. The API got a complete rewrite and is therefore not anymore compatible with SmallBASIC PiGPIO 1.

Function Reference and Examples

  • Generic GPIO: Digital input and output
  • Generic I2C: Generic I2C and SMBus interface
  • Generic SPI: Generic SPI interface
  • PWM: PWM output
  • Framebuffer: Graphics output to the Linux framebuffer
  • SSD1306 compatible OLED Display: Graphics on this a small and cheap b&w OLED display
  • ADS1015 and ADS1115 Voltage Sensor: Measure voltages
  • BMP180: Measure temperature and pressure
  • MPU6050: Accelerometer and gyroscope
  • ST7789: SPI color display
  • HD44780: Text display - coming soon
  • DS18B20: Temperature sensor - coming soon

Supported Hardware

  • ADS1015 and ADS1115: Analog to Digital Converter (Voltage Sensor)
  • BH1750: Ambient Light Sensor (generic I2C)
  • BMP180: Temperature and Pressure Sensor
  • BMP280: Temperature and Pressure Sensor (generic SPI)
  • LED: Control a LED (generic GPIO)
  • MPU6050: Accelerometer and Gyroscope
  • Pi Sugar 3 plus: Battery/USB power supply and charger (generic I2C)
  • Push Button: Read buttons (generic GPIO)
  • SSD1306: OLED Display
  • ST7789: SPI color display
