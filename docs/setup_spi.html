Setup SPI on the Raspberry Pi

Desktop

  • Open the menu.
  • Select “Preferences”
  • Start “Raspberry Pi Configuration”
  • Open the tab “Interfaces”
  • Enable “SPI”
  • Save settings
  • Restart Raspberry Pi

Command Line (Terminal)

  • Type “sudo raspi-config”
  • Select “Interface Options”
  • Select “I3 SPI”
  • Select “Yes”
